# Eat Your Meat

A concept site for a whole-animal butcher shop in Williamsburg, Brooklyn. Every farm, price and stock count is sample data, and a notice at the top of each page says so.

## Run

```sh
node build.mjs                  # writes index.html, cuts/*.html, the info pages, sitemap.xml, robots.txt
node test/store.test.js         # pricing by weight, stock caps, fees, ZIP rules, Eastern-time schedules
python -m http.server 5173      # then open http://127.0.0.1:5173 (opening index.html from disk also works)
```

There are no dependencies to install: you only need Node 20+ to build and test.

## Layout

| Path | What it is |
|---|---|
| `js/data.js` | Catalog: this week's animals, farms, items by the pound, the box picks, special orders |
| `js/store.js` | Pure logic: weight and price, cart with stock caps, fees, ZIP classifier, cutoffs in Eastern time |
| `js/render.js` | HTML builders shared by the build and the browser: board, freezer labels, cut diagrams, product page |
| `js/app.js` | Browser behavior: board filters, cart, checkout, search, Butcher's Box, account, gift cards |
| `src/home.html` | Homepage template |
| `content/pages.mjs` | Copy for About, Delivery, FAQ, Contact, Refunds, Shipping, Privacy, Terms, Food safety, Accessibility |
| `content/nyc-map.svg` | Courier-zone map, simplified from NYC borough boundaries |
| `assets/img` | Stock photos (Unsplash). Sources are in `credits.json` |
| `assets/fonts` | Rokkitt and Public Sans (OFL), self-hosted |

Every page under `cuts/` and the info pages is generated by the build, so edit the source files, not the output. `audit/` holds the design audit this version answers. It is not part of the site, so leave it out when you deploy.

## Before this takes real money

- Shoot your own photos. The stock photos are only the same kind of cut, and some cuts have none.
- Replace the sample farms, animals, stock and contact details with real ones.
- Have a lawyer review the terms, privacy and refund pages, and connect a real payment processor.
